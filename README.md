# Meme Market Cap Index (MMCI)

A decentralized index and allocation system for XRPL meme tokens with automated basket management.

---

## Project Overview

Meme Coin Market Cap Index (MMCI) is a **DeFi-inspired system** built on the XRP Ledger (XRPL) that automatically manages a basket of meme tokens. The system:

- Allocates **55% of funds to a curated meme token basket**.
- Allocates **15% XRP liquidity pool support for MMCI/XRP AMM**.
- Allocates **15% for operational and development costs (Server + hosting, Marketing, Moderators, Treasury automation systems, Data feeds + dashboard)**.
- Allocates **15% for — Developer Wallet (Development & upgrades, Security audits, Vision continuity, Founder/dev compensation)**.
- Provides transparency and efficiency for XRP holders interested in meme token exposure.

MMCI celebrates the lore and community of XRPL meme tokens while providing a structured and automated way to engage with them.

---

## Key Features

- **Automated Allocation:** Smart logic to manage token distribution according to MMC rules.
- **Basket Management:** Curated selection of meme tokens reflecting XRPL culture and history.
- **Operational Transparency:** All transactions executed on XRPL are fully auditable.
- **DeFi-Inspired:** Enables structured exposure to meme tokens while leveraging XRPL’s fast, low-cost network.
